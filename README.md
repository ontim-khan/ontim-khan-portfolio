## Run the portfolio
1. Extract the complete ZIP file.
2. Keep `index.html`, `style.css`, `script.js`, `assets/`, and `downloads/` together.
3. Open `index.html` in a browser.

## Important: how to run the PHP projects
These are PHP/MySQL web applications, so opening their `.php` files directly in a browser will not run them. Install XAMPP (or another PHP + MySQL stack), extract a project into the server's `htdocs` folder, start Apache and MySQL, import the included `.sql` database file through phpMyAdmin, and check the project's database connection settings before opening it at `http://localhost/...`. Change default credentials before using the project anywhere public.
